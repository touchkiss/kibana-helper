# Kibana Helper

一个强大的 Kibana 用户脚本,增强日志查看体验。

## 快速开始

查看完整文档: [README.md](README.md)

## 主要功能

- 🔍 自动展开日志
- 🎨 智能高亮显示 (ERROR/WARN 级别 + 关键字)
- 🔗 可点击 ID 快速跳转 (trace.id / request_id)
- ⚡ 实时响应 DOM 变化

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 [安装脚本](kibana-helper.user.js)
3. 刷新 Kibana 页面即可使用
